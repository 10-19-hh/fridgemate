## 완료한 선행 작업: 초안과 확정본의 분리

생성·편집은 초안에만 저장한다. 명시적 확정이 저장된 뒤 기존 확정본을 교체하고 이전
확정본을 같은 트랜잭션으로 보관한다. 주별 레코드는 v2, 내부 식단은 v1 스냅샷이다.
기존 v1 자료는 읽기만으로 바꾸거나 확정하지 않는다. 이 단계에서는 IndexedDB 버전/저장소를
유지했고, 이후 수량 확인 작업에서 DB v4가 추가됐다.
저장·확정의 정확한 revision 비교, 실패·동시 요청·계정/주차 경계와 새로고침을 검증했다.
수량 미검수 상태는 유지하고 실제 재고를 변경하지 않는다.

단위·상태 호환성과 정밀도 한계를 처리한다. `반 모`나 팬트리 보유를 정량 재고로 바꾸지 않는다.

읽기 전용 장보기 미리보기에서 실제 저장소의 여러 주·재고를 사용한다. 후속 검증에서는
실제 수량 저장 API로 확인한 300g 재고/합성 200g 두 끼에서 100g 부족을 검증했고 기존 재구매 메모를
보존했다. 실제 기본 메뉴는 미검수 재료 안내로 남는다. 결과에는 읽은 시각을 표시하며
창 복귀·계정/저장 버전 변경 시 이전 결과를 폐기한다. 실시간 재고 구독은 아니다.
