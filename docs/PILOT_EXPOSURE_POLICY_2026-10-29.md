## 먼저 볼 요약

1. **실제 Preview 검증 미완료:** 별도 설정의 원격 적용, 비로그인 접근, 직접 접근·새로고침·CSP·noindex·404·금지 외부 요청을 아직 확인하지 않았다.
2. **고정 참가 origin 미확정:** 기존 브랜치 Preview는 운영으로 리다이렉트됐다. 참가자에게 배포할 URL, 접근 보호, 파일럿 기간 유지·호환 롤백을 확인하기 전에는 모집하지 않는다.
3. **수동 JSON 회수 운영 미확정:** 수신자·전달 채널·내려받은 사본의 삭제 날짜가 정해지지 않았다. 브라우저의 35일 정리 정책으로 이를 대신하지 않는다.

### 필요한 결정 3개

1. **참가 주소 운영:** 어느 고정 origin을 사용할지, 익명 참가자가 어떻게 접근할지, 같은 origin에서 누가 업데이트·롤백을 관리할지 확정한다.
2. **제출 파일 운영:** JSON 수신자·전달 채널·접근 범위·사본 삭제 날짜를 모집 전에 확정한다. 이 문서에서 임의의 담당자나 날짜를 지정하지 않는다.
3. **모집 실행:** 위 두 결정과 원격 스모크 이후 실제 시작·종료 날짜, 참가 안내 확정본, 실기기·OCR 검증 일정을 확정한다. 기존 성공·중단 기준은 관측 결과를 보고 바꾸지 않는다.

빌드 분리는 화면 표시뿐 아니라 신규 참여·재개·관측 진입점에도 적용해야 한다. 과거 동의나 수집 중 상태가 남아 있어도 일반 빌드가 관측을 이어가서는 안 된다. 사용자가 실제 비즈니스 동작을 완료했지만 파일럿 관측만 실패한 경우에는 기존 원칙대로 비즈니스 저장을 보존하고 누락을 사실대로 표시한다.

`VITE_LOCAL_PILOT_ENABLED`는 전용 빌드의 제품 정책이다. 일반 분석 동의와 같지 않고, 해당 플래그가 켜졌다는 이유만으로 파일럿 수집에 동의한 것으로 취급하지 않는다. 서버 모드나 인증 기능을 새로 구현하는 작업도 아니다.

- 이번 파일럿의 허용 목적은 **메뉴 선택·장보기·조리 흐름의 제품 사용성 검증**이다. 연구·모델 학습·다른 목적으로 활용하는 것은 이번 승인 범위 밖이다. 해당 목적을 자동으로 추가하거나 기존 동의가 이를 포괄한다고 해석하지 않는다.

위 내용은 제품 범위와 기술적 동작의 구분이다. 개인정보 법적 적합성이나 연구 동의 요건을 판정한 문서가 아니다. 향후 목적 확대는 별도 사용자 결정과 필요한 개인정보 검토를 거친다.

- 첫 일반 빌드는 sandbox의 로컬 Vite 포트 `EPERM` 경고가 있었으나 종료 코드와 산출물 검증은 0이었다. 로컬 포트를 허용한 새 일반/파일럿 빌드를 다시 실행해 해당 경고 없이 성공한 결과를 최종 근거로 사용했다.
- 첫 전체 브라우저 검사는 기존 107개 중 104개 통과·파일럿 참여 3개 실패였다. 일반 빌드가 참여를 막는 새 정책과 충돌하므로 **세 시나리오와 helper·assertion을 그대로** `e2e/pilot-capture.spec.js`로 이동해 실제 전용 빌드에서 검증했다. 일반 환경에는 참여 차단·식단 생성/확정 보존 검사 1개를 추가했다. 따라서 현재 대상은 일반 105개·파일럿 9개이며 과거 107개·6개와 단순 증감 비교하지 않는다.
- 로컬 포트 권한 부족·동시 실행 포트 충돌로 테스트 0개인 시도는 환경 오류로 별도 남겼으며 PASS나 정책 재현으로 세지 않았다. 테스트 timeout·재시도·기대 점수·skip 설정은 완화하지 않았다.

### 실행 명령과 증거 위치

대상 cwd는 이 작업 트리이며 Node 24 실행 경로를 우선 사용했다. 일반 자식 검사 프로세스에는 모델 API 키를 전달하지 않는 환경 allowlist runner를 사용했다. 실제 명령은 아래와 같고, 고유 이름의 `.log`와 `.meta.json`에 종료 코드·시간을 기록했다.

```sh
npm run test:run -- --reporter=json --outputFile=/private/tmp/fridgemate-pilot-policy-20261029-GcaR3K6O/unit-verified.json
npm run lint
npm run build
npm run build:pilot
npm run test:e2e -- --workers=2 --reporter=json
npm run test:e2e:preview -- --reporter=json
npm run test:e2e -- --config playwright.pilot.config.js --reporter=json
git diff --check
```

- 최종 증거 폴더: `/private/tmp/fridgemate-pilot-policy-20261029-GcaR3K6O`. `unit-verified.json`, `lint-complete.log`, `build-verified.log`, `pilot-build-verified.log`, `built-e2e-verified.log`, `pilot-e2e-final.log`, `e2e-complete.log`가 최종 근거다. 임시 증거는 OS 정리 대상이며 이 문서의 실행 요약과 소스 커밋을 영구 보존 수단으로 사용한다.
